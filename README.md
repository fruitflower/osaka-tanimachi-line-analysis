# Osakaメトロ谷町線の住環境・比較ダッシュボード

## 1. 作品概要

大阪メトロ谷町線の全26駅を対象に、住まい選びに関わる複数の指標を比較できるダッシュボードを制作しました。

家賃、駅の利用者数、買い物環境、自転車盗難件数、洪水浸水想定区域のデータを収集・加工し、駅ごとの特徴を確認できるようにしています。

住まい選びでは、家賃の安さ、買い物の利便性、防災面など、人によって重視する条件が異なります。本作品では独自の総合点による順位付けを行わず、各指標の実際の数値を比較することで、利用者自身が希望する条件に合わせて駅を検討できることを目指しました。

### ダッシュボード

[Tableau Publicでダッシュボードを見る](https://public.tableau.com/app/profile/.80443315/viz/Osaka_r1/Osaka)

- 対象：大阪メトロ谷町線 全26駅
- 内容：家賃、駅の利用者数、買い物環境、自転車盗難件数、洪水浸水想定区域
- 特徴：路線図から駅を選択し、各駅の指標を比較できる構成

## 3. 使用データ・出典

各データの取得・集計時期は2026年9月です。データごとに対象期間や集計方法が異なるため、出典と加工方法を以下に記載します。

### 3.1 家賃情報

- 対象：2LDK・3LDKの家賃
- 単位：万円／月
- 出典：[CHINTAI](https://www.chintai.net/)
- 取得日：2LDKは2026年9月22日、3LDKは2026年9月21日

住居費を比較するために使用しました。家賃は取得時点の情報であり、実際の募集状況や契約条件によって異なる場合があります。

### 3.2 駅の利用者数

- 対象：谷町線各駅の乗降人員
- 単位：人／日
- 出典：[Osaka Metro「路線別駅別乗降人員」](https://www.osakametro.co.jp/company/library/100331_research/20251111_subway_nt.pdf)
- 公開資料の日付：2025年11月11日

駅の利用規模を比較するために使用しました。乗降人員は、乗車人数と降車人数を合わせた数値です。

### 3.3 スーパーマーケット数・大型商業施設数

- 対象：スーパーマーケット・ディスカウントショップ、大型商業施設
- 単位：件
- 出典：[GeoMedian](https://geomedian.com/)
- 集計範囲：各駅から半径800m以内
- 集計日：2026年9月23日

駅周辺の買い物環境を比較するために使用しました。

商業施設数は、GeoMedianの駅周辺情報を基に整理したものです。施設の掲載状況や分類に依存するため、すべての店舗・施設を網羅するとは限りません。

### 3.4 自転車盗難件数

- 対象：自転車盗難の発生情報
- 単位：件
- 対象期間：2025年
- 出典：[大阪府警察「犯罪オープンデータサイト」](https://www.police.pref.osaka.lg.jp/seikatsu/24614.html)
- 位置情報：Geoloniaの住所データ

#### 加工方法

1. 大阪府警察の公開データから対象地域の自転車盗難情報を抽出しました。
2. 市区町村・町丁目ごとに発生件数を集計しました。
3. Geoloniaの住所データを使用し、町丁目の代表地点の緯度・経度を取得しました。
4. Haversine式を用いて、駅と町丁目の代表地点との直線距離を計算しました。
5. 駅から800m以内に代表地点がある町丁目の発生件数を、駅ごとに合計しました。

この指標は、駅から半径800m以内に町丁目の代表地点がある地域の発生件数を集計したものです。町丁目の境界全体が800m圏内に含まれるかどうかで判定したものではありません。

また、住所データと一致しない町丁目や、座標を取得できなかった町丁目は集計から漏れる可能性があります。

同じ町丁目が複数駅の800m圏内に含まれる場合、それぞれの駅の集計に含まれます。そのため、駅ごとの件数を単純に合計しても、対象地域全体の発生件数とは一致しない場合があります。

### 3.5 洪水浸水想定区域

- 対象：想定最大規模の洪水浸水想定区域
- 単位：％
- 出典：[国土交通省「国土数値情報 洪水浸水想定区域データ（A31a）」](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A31a-2025.html)
- 使用ファイル：`A31a-25_27_10_GEOJSON.zip`

#### 加工方法

大阪メトロ谷町線の各駅を中心とした半径800mの範囲と、洪水浸水想定区域のポリゴンデータを重ね合わせました。そのうえで、800m圏内の面積に対して、洪水浸水想定区域が占める面積の割合を算出しました。

この指標は、駅周辺の範囲のうち、洪水浸水想定区域に含まれる面積の割合を示します。浸水の発生確率や、個々の建物が浸水する確率を示すものではありません。

## 4. データ加工・分析方法

### 4.1 Pythonによるデータ加工

Python、pandas、NumPyを使用し、CSVデータの読み込み、前処理、位置情報を用いた距離計算、集計を行いました。

複数のデータソースから得られた指標を駅単位で整理し、比較・分析に利用できる形式に加工しました。

自転車盗難データでは、町丁目単位の発生件数と位置情報を組み合わせ、駅から800m以内にある町丁目の代表地点を基準に集計しました。

洪水浸水想定区域データでは、駅から半径800mの範囲と浸水想定区域を重ね合わせ、対象範囲に占める浸水想定区域の面積割合を算出しました。

### 4.2 SQL・Google BigQueryによる分析

Google BigQueryにデータを格納し、SQLを使用してデータの抽出・集計・分析を行いました。

駅番号をキーとして各データを整理し、駅ごとの指標を比較できる分析用データを作成しました。

また、各駅の指標について、谷町線26駅の平均値との差と、平均値に対する差の割合を算出しました。これにより、各駅の数値が路線全体の平均と比べてどの程度異なるかを確認できるようにしました。

### 4.3 Tableau Publicによる可視化

Tableau Publicを使用し、谷町線の路線図と指標比較を組み合わせたダッシュボードを作成しました。

路線図から駅を選択すると、選択した駅に対応する指標を確認できる構成にしています。

家賃、駅の利用者数、買い物環境、自転車盗難件数、洪水浸水想定区域などを確認することで、複数の観点から駅ごとの特徴を比較できます。

特定の駅を一律に順位付けするのではなく、実際の数値をもとに、利用者自身が比較・判断できる可視化を意識しました。

## 5. ダッシュボードの使い方

1. ダッシュボード上の路線図から、比較したい駅を選択します。
2. 選択した駅に対応する指標を確認します。
3. 家賃、買い物環境、駅の利用者数、防災などの観点から、駅ごとの特徴を比較します。

各指標の数値を確認しながら、自分が重視する条件に合わせて駅を検討できます。

## 6. 分析上の注意点

- 指標によって対象期間や集計範囲が異なります。
- 家賃情報は2026年9月に取得した情報であり、現在の募集状況や実際の契約条件と異なる場合があります。
- 駅の利用者数は、2025年11月11日付の交通調査資料に基づく乗降人員です。
- 店舗数・施設数は使用した位置情報データに基づく集計であり、すべての店舗・施設を網羅するとは限りません。
- 自転車盗難件数は、町丁目の代表地点と駅との直線距離を用いて集計しています。そのため、駅周辺で実際に発生した件数と一致するとは限りません。
- 自転車盗難件数は地域の治安全体を直接示すものではありません。人口や自転車の利用状況なども考慮する必要があります。
- 洪水浸水想定区域の面積割合は、想定最大規模の洪水浸水想定区域データに基づく指標です。浸水の発生確率や、個々の建物の浸水可能性を示すものではありません。
- 実際の浸水状況は、降雨や河川の状況などによって異なります。
- 本作品は駅選びの参考情報を提供するものであり、居住環境のすべてを評価するものではありません。

## 7. 制作を通じて取り組んだこと

日常生活に関わる「住まい選び」をテーマに、複数のデータソースから情報を収集し、Pythonによる加工、SQLによる集計・分析、Tableauによる可視化までの一連の工程に取り組みました。

データを単に集計・表示するだけでなく、指標ごとの単位や集計条件の違いを踏まえ、出典、加工方法、解釈上の注意点を整理しました。

また、総合点による一律の順位付けを避け、利用者が実際の数値を比較し、自分の優先条件に応じて判断できる構成を意識しました。

本作品を通じて、複数のデータを分析可能な形に整え、利用者が比較・判断に活用できる情報として可視化することに取り組みました。
